# 三分钟现场演示

1. 先说明顶栏的“机制演示”：人物、场次、同意和时钟都是构造数据，没有钱包交易。
2. 选择“接上一个候补”，点击“查看换位方案”。小林持上午、小陈持下午，小雨候补，周日下午空着。
3. 模拟全部同意并执行：3 席从 2 人变为 3 人。数字是本例机制结果。
4. 重置，查看方案并全部同意，再让小陈撤回，点击执行：旧方案失败，已有位置保持不变。
5. 切换“两人互换时间”：执行成功但人数增量为零。切换“没有合适的空位”：保持现状。
6. 打开证据区：浏览器独立复算本地 EVM 事件，与合约快照一致。明确 31337 是本地 EVM，10143 只是已核对的目标网络；应用尚未部署。
7. 在终端运行 `pnpm test` 和 `pnpm verify:events`。测试网真实交易与最终确认耗时只在完成真实接入后补充。

终端成功输出、网页截图和下载记录各有用途，不以截图替代链上证明。
