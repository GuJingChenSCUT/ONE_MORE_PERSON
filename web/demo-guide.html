Set up / 演示准备

Open the three links above in the same browser profile. Use normal tabs; do not mix normal and incognito windows. Keep room=stage in all links. Alice can expand Presenter controls & safety challenges and select Restart this room before the presentation.

三个链接必须在同一浏览器配置中打开，房间名称保持一致。不要混用隐身窗口。Alice 可以展开“演示控制与安全挑战”，选择“重新开始本房间”。每个页面只操作自己的角色。

Live rundown / 现场流程 · 3–4 min

  1. Show the starting seats. Alice has Saturday morning, Bob has afternoon, Charlie waits, Sunday is empty.
    展示：Alice 上午、Bob 下午、Charlie 候补、周日空缺。

  2. Alice: Approve pool as Host A. Bob: Approve pool as Host B. Switch to Charlie and show the progress updating.
    Alice 与 Bob 分别确认主办方席位池，Charlie 页面同步变化。

  3. Alice: Create shared plan. On all three pages, select Approve my move. The old seats stay in place.
    Alice 创建共享方案，三人分别同意。仅同意不会释放原位。

  4. Bob: Withdraw my approval. Alice: Try withdrawn plan. All pages show rejection and unchanged seats.
    Bob 撤回，Alice 尝试已撤回方案。三页显示失败，所有原位保留。

  5. Alice: Create fresh plan. All three pages select Approve my move again.
    Alice 创建新方案，三人重新同意。

  6. Alice: Execute all 3 moves. Every page now shows Charlie / Alice / Bob and 3 / 3.
    Alice 执行三人换位。三个页面同时显示 Charlie / Alice / Bob，参加人数由 2 变为 3。

  7. Open Monad proof. State clearly: this public interaction is a simulation; the proof is a separate verified Testnet transaction.
    打开 Monad 链上证据，明确公网交互为模拟，测试网证据为独立的真实交易记录。

How the effect works / 同步原理

Each role page reads one room record in browser storage. A browser lock serializes simultaneous actions. Storage events and BroadcastChannel notify the other pages immediately; returning to a tab reads the newest state again. Refresh preserves the room. This does not synchronize other devices or browser profiles and is not production authentication.

三个角色页面读取同一份浏览器房间记录。浏览器锁顺序处理同时发生的操作，其他标签页收到变化通知后刷新状态。刷新网页不丢失房间；不同设备、不同浏览器配置不会互通。这不是正式身份认证。

Keep the real local deployment / 保留本地真实合约版

Double-click Start-Demo.cmd in the repository to open the original local Alice, Bob and Charlie pages. That separate service uses real EIP-712 signatures and the unchanged SafeSeatRelay contract on isolated EVM chain 31337. Its three pages share live server events. The public proof runs on Monad Testnet chain 10143.

本地版继续通过项目中的 Start-Demo.cmd 启动，执行真实签名与本地 EVM 合约交易。查看本地版四页 PDF 操作说明。

Recovery / 故障恢复

If pages disagree, check that their room names and browser profiles match, then refresh. Close duplicate tabs for the same role if they are confusing. Alice can restart the shared room for another run. To preserve the public result first, use Download simulation record; the export explicitly labels itself a simulation.

若三页不同步，先检查房间名、浏览器配置是否一致，再刷新。出现重复角色页面时关闭多余页面。Alice 可重新开始；需要保留结果时先下载模拟记录。

The public demo contains fictional people, simulated approvals and predefined moves. It does not measure Monad performance or prove a real-user pilot.
