## 测试网证明夹具

`contracts/demo/RelayProofFixture.sol` 只用于测试：四个虚构角色由同一控制者管理，不能当成独立机构或真实参与者的签名。它部署未改动的 `SafeSeatRelay`，通过 ERC-1271 的已授权摘要验证路径执行机制。

`node scripts/compile-proof.mjs` 保存包含全部 17 个 Solidity 来源的标准编译输入，方便部署后验证。`node --test tests/proof-fixture.test.mjs` 已通过本地检查：缺少一个授权摘要时，内部调用回滚且席位、nonce 不变；补全后 2 人变 3 人；重复方案拒绝；公开事件可独立重建最终席位。

夹具的外层 `runProof` 交易应成功，内部有两次被捕获的拒绝。不要把这两次拒绝说成两笔失败的外层交易。该夹具仅允许 31337 / 10143，没有业务资金或真实席位。

**尚未取得测试网部署和交易证据时，所有实链地址保持空值。** 账户登录、钱包会话、测试 MON 余额、部署回执、finalized 区块与源码验证均须分别实际核对后才能更新状态。
